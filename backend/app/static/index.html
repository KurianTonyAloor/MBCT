System Architecture

The MBCT system decouples user intent (UBP sliders) from model-specific mechanics (MCP vectors). Steering is applied at inference-time only — model weights are never modified.

┌─────────────────────────────────────────────────────────────────────────────┐ │ MBCT — System Data Flow │ ├─────────────────────────────────────────────────────────────────────────────┤ │ │ │ PERSONALITY STUDIO ──sliders 0-100%──▶ Universal Behaviour Profile (UBP)│ │ │ │ │ ▼ │ │ Calibration Wizard ──runs once──────▶ PersonalityCompiler │ │ Ollama phi3 (pairs generator) UBP × MCP → CompiledSteeringPlan │ │ Phi-3 Mini (teacher-forced) α[trait,layer] = (s-0.5)×2×3 │ │ VectorDeriver (mean diff + norm) │ │ │ MCP → artifacts/profiles/mcp.json ▼ │ │ SteeringController │ │ FROZEN MODEL ◀─────hooks──────────────── ActivationHookManager │ │ Phi-3 Mini 3.8B h'ₗ = hₗ + Σ α[t,l]·v[t,l] │ │ (32 transformer layers) Layers: 12, 14, 16 │ │ No weight modification │ │ │ │ │ Streaming SSE ◀──/api/steering/generate/stream──────┘ │ │ Side-by-side ◀──/api/steering/generate (blocking) │ │ │ │ Kill-Switch: master_enabled=False → hooks pass through unchanged │ └─────────────────────────────────────────────────────────────────────────────┘

UBP — Universal Behaviour Profile

Model-agnostic. Human-readable sliders (0–100%). Stored per-session. Can be serialised to JSON for sharing across model variants.

MCP — Model Calibration Profile

Model-specific. Stores unit-normalised steering vectors per trait per layer. Generated once via contrastive activation diff. Persisted to artifacts/profiles/mcp_*.json.

Compiled Steering Plan

Runtime artefact. Resolved alpha per layer: α = (slider − 0.5) × 2 × max_alpha. Positive = towards trait pole; negative = away. Applied via forward hooks on frozen model.
